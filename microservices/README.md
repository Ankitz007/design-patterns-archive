# Microservices Design Patterns

This folder contains flash cards for various microservices design patterns. The flashcards are designed to help you understand these patterns and their applications in real-world scenarios in quick time.

## Contents

So far, the following microservices design patterns have been included:

- **[Strangler Fig Pattern](strangler_fig/README.md)**: A pattern that allows you to gradually migrate a monolithic application to a microservices architecture by creating a new microservice alongside the existing monolith and gradually moving functionality from the monolith to the new microservice.
